# ケミカラ 開発メモ（Claude Code 向け）

## このプロジェクト
高校化学の学習ゲーム。利用者は高校生（主に iPad の Safari）。UI はすべて日本語。
作者は高校の化学教員。内容の正確さ（高校化学の教科書レベル）を最優先にする。

## 必ず守ること
- 変更後は `python3 build.py` と `node tools/check_recipes.js` を実行し、両方成功させる
- 出力は 1 ファイルの HTML（外部読み込みは Google Fonts のみ）。ビルド結果 `dist/` もコミットする
- `APP.saveKey` は変えない（生徒の記録が消える）。保存データの形を変えるときは古いデータも読めるようにする
- 合成レシピは係数まで正しい化学反応式にする（チェックスクリプトで原子の数を検証）
- 化学的な説明は短く、教科書の用語で。あいまいな場合は一般的な高校教科書の記述に合わせる

## クイズの出題ルール（作者の方針）
- Lv.1（序盤）は「緑」と「淡緑」のような似た色名・同じ漢字を含む色名を同時に出さない。Lv.3 では積極的に出す
- 「無色」は答えとして 1 単元に最大 1 問。選択肢には「ひっかけ」のとき以外は出さない
- スワイプ（2択）の選択肢は左右固定（`swipe.pick` で順番を決める。保存方法のように組が変わる単元は問題ごとに `pair` で固定）
- 4択の選択肢・問題文の言い回し（`prompts`）・ボス（`boss:1` の候補から1つ）は毎回ランダム
- 共通テストまでのカウントダウンは全単元のスタート画面とメニューに出す。日付は `common.js` の規則で毎年自動計算
  （1月13日以降の最初の土曜日）。公式発表と違う年は `KYOTSU_FIXED` に追加する
- デザインは男女どちらにも受けるポップ系（ピンク・ハート多用は避ける）

## 構成
- `src/engine/base.html`：クイズ本体。`/*COMMON*/` `/*DATA*/` `/*LAB*/` の位置にデータが差し込まれる
- `src/engine/rewards.*`：ランキング・ごほうび・合成ラボ（ごほうび版と有機版で使用）
- `src/data/`：単元・問題・レシピのデータ。新しい単元はここに追加する
- エディションの組み合わせは `build.py` の `EDITIONS`
