# ケミカラ！ 化学の色・反応クイズ

高校化学（無機・有機）を、iPad／スマホのブラウザで遊びながら覚えるクイズゲームです。
ビルドすると **1ファイルで動く HTML** ができるので、サーバーがなくても配布・公開できます。

## エディション（`dist/` に出力）

| ファイル | 内容 |
|---|---|
| `inorganic.html` | 無機・基本版（色クイズ・捕集法・沈殿・におい・保存方法・工業的製法）。ランキングやごほうびなし |
| `chemicolor.html` | **総合版**。無機／有機／高分子をメニューのタブで切り替え。ランキング・コイン・バッジ・素材ガチャ・合成ラボつき |
| `index.html` | トップページ（上の2つへのリンク集） |
| `inorganic-rank.html`・`organic.html` | 以前の URL。開くと総合版へ自動で移動（有機版は有機タブで開く） |

### 総合版のしくみ

- **分野タブ**：無機・有機・高分子。単元・ガチャ・合成ラボ・図鑑・ランキングが分野ごとに切り替わる（高分子はクイズだけで、合成ラボ・ガチャ・図鑑はなし）。
  コイン・レベル・バッジ・持っている素材は全分野で共通
- **素材ガチャ**：1回🪙50（素材5枚）。無機タブは無機の素材、有機タブは有機の素材が出る。高分子の単元をクリアすると、無機・有機の素材がもらえる
- **コンプまでの目安**：全単元を約3周、または毎日ログインで約3.5週間で、無機・有機の全レシピがそろう（ログインボーナスは1日🪙140〜260）。
  クリアやログインのたびに「おたすけ素材」（まだ作っていないレシピに足りない素材）が配られる。
  配る枚数はデータから自動計算するので、レシピを増やしても目安は変わらない（調整は `lab-core.js` の `GOAL_LAPS`・`GOAL_DAYS`・`HELP`）
- **プレイヤー登録**：ニックネーム＋4けたの合言葉。ランキングには合言葉を登録したプレイヤーだけがのる。
  以前から遊んでいる人は、名前を選ぶと合言葉の設定画面が出る
- **ランキング**：今は「この端末」のみ。「クラス全体」タブは画面だけ用意してあり、記録の送り先（サーバー）を決めたら
  `rewards.js` の `CLASS_RANK` に実装する
- **合成ラボ**：未発見のレシピは 🪙50 で「材料と係数」を見られる（ヒント）。合成の演出は、加熱・高圧・触媒・光・放電・燃焼・沈殿・気体の発生・重合などの条件で変わる
- **バッジ**：プレイ・記録・コイン・ガチャ・合成・各分野の物質など約80種類（`rewards.js` の `BADGES` と各 `*-lab.js` の `LAB_BADGES`）
- **記録の引き継ぎ**：以前の有機版の記録は、総合版を初めて開いたときに自動で合算される（元の記録は消さない）

## フォルダ構成

```
src/
  engine/
    base.html      … クイズ本体（4択モード・スワイプ2択モード・結果まとめ）
    rewards.js/css … ランキング・コイン・バッジ・ガチャ・合成ラボの画面
    lab-core.js    … 分野の切り替え・合成ラボの共通部品・ガチャ確率・おたすけ素材の計算
    lab-fx.js      … 合成の演出（反応の条件ごとに容器と効果を変える）
  data/
    common.js          … 色の定義（HEX）・色の系統（FAM）など全版共通
    inorganic.js       … 無機の単元・問題
    inorganic-lab.js   … 無機の素材・物質・レシピ
    organic.js         … 有機の単元・問題
    organic-lab.js     … 有機の素材・物質・レシピ
    polymer.js         … 高分子の単元・問題（高分子は合成ラボなし）
tools/check_recipes.js … レシピの原子の数・重複などを自動チェック
tools/sim_collect.js   … コンプまでのペース（何周・何日）をシミュレーション
src/index.html         … トップページ（3つの版へのリンク集。ビルドで dist/ にコピー）
build.py               … src を組み合わせて dist/*.html を作る
.github/workflows/pages.yml … main への push で build.py を実行し GitHub Pages に公開
```

## 使い方

```bash
python3 build.py              # dist/ に全エディションを出力
node tools/check_recipes.js   # 合成レシピの検査（両辺の原子の数がそろっているか など）
node tools/sim_collect.js     # コンプまでのペースの確認（レシピや報酬を変えたとき）
```

## 問題・レシピの追加

- **4択の色クイズ**：`src/data/*.js` の `CH[].q` に `{fm, nm, c, d, trap, hint}` を追加
  - `c` は `common.js` の `HEX` にある色名。`d` は難易度 1〜3（Lv.1 では似た色名は選択肢に出ない）
  - 色以外の4択（におい・触媒・単量体・繊維）は、単元に `noSim:1`・`icon`（選択肢の絵）・`art`（答えの絵）を指定する
  - 問題ごとに選択肢を決めたいときは `opts:[まちがいの候補…]`、問いかけを変えたいときは `ask:"触媒は？"`（工業的製法の単元）
- **出題のしかた**：各単元 20 題前後から毎回ランダムに 10 題（Lv.1：4・Lv.2：4・Lv.3：2）。選択肢・ボスも毎回ランダム
  - 同じ話題の問題に `g:"話題名"` をつけると、1回の出題では1問だけになる（例：Cu²⁺ と CuSO₄ 水溶液）
- **スワイプ（2択）**：`mode:"swipe"` の単元に `{nm, fm, ans, d, boss, hint}` を追加（`swipe.opts` が2つの選択肢）
- **新しい分野**：`src/data/○○.js` と `○○-lab.js` を作り、`build.py` の `FIELDS` に1行足す
- **合成レシピ**：`src/data/*-lab.js` の `RECIPES` に `[{材料:係数}, {生成物:係数}, "ヒント", "条件"]`
  - 条件（省略可）は合成の演出に使う：`heat`（加熱）・`press`（高圧）・`cool`（冷却）・`cat:Fe₃O₄`（触媒）・`ppt`（沈殿）・`-ppt`（打ち消し）など。
    ヒント文の「加熱」「光」「燃える」「沈殿」なども自動で読み取る（`src/engine/lab-fx.js`）
  - 高分子は `(…)<sub>n</sub>` で書く。検査では n＝5 として数えるので「単量体5枚 → 高分子1枚」にする
  - 係数＝必要なカード枚数。触媒は材料と生成物の両方に入れる（変化しないことが伝わる）
  - 追加したら必ず `node tools/check_recipes.js` で確認

## 共通テストのカウントダウン

`src/data/common.js` の `kyotsuDay1()` が「1月13日以降の最初の土曜日」を計算します（2021〜2027年度の実際の日程と一致）。
大学入試センターの発表と違う年があれば `KYOTSU_FIXED` に `年: [月-1, 日]` を追加してください。

## 公開（GitHub Pages）

`main` に push するたびに GitHub Actions（`.github/workflows/pages.yml`）が `build.py` を実行し、
`dist/` を GitHub Pages に公開します。生徒は URL を開くだけで遊べます（ログイン不要）。

**最初に1回だけ設定**：リポジトリの Settings → Pages を開き、
Build and deployment の **Source** を **GitHub Actions** にします。

- トップページ：`https://<ユーザー名>.github.io/<リポジトリ名>/`（各版へのリンク集。元は `src/index.html`）
- 各版：上の URL の後ろに `inorganic.html`（基本版）/ `chemicolor.html`（総合版）
- 公開の進み具合やエラーは、リポジトリの Actions タブで確認できます

## データの保存について

記録（スコア・コイン・図鑑）は各端末のブラウザ（localStorage）に保存されます。
総合版の保存キーは `chemicolor-rank-v1`（以前のランキング版と同じ。`build.py` の `SAVE_KEY`）。キーを変えると記録が消えるので注意。
合言葉はこの端末にハッシュで保存されます。
合言葉を忘れたときは、合言葉の入力画面の「🔑 合言葉をわすれた」から、先生が「先生用コード」を入れると決め直せます（記録はそのまま）。
先生用コードはハッシュだけを `build.py` の `TEACHER_CODE_SHA256` に置いています。変えるときは、そこに書いてある手順で新しいハッシュを作ります。
